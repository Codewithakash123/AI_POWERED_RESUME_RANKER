# AI_POWERED_RESUME_RANKER

## Project Description

AI-Powered Resume Ranker is a web-based application that ranks resumes according to a given job description using Natural Language Processing and Machine Learning techniques.

## Technologies Used

- Python
- Flask
- SpaCy
- Scikit-learn
- TF-IDF
- Cosine Similarity
- PyPDF

## Features

- Enter a job description
- Upload multiple PDF resumes
- Extract text from PDF resumes
- Preprocess resume text
- Calculate resume-job similarity
- Rank candidates automatically
- Display resume scores and status
- Download HR ranking report as CSV
